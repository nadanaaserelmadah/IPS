# Figure scripts for the manuscript

Scripts in this folder: `sr_style.py` (shared journal style), `fig_heading_error.py` (Figure 3) and `fig_measure_vs_learn.py` (Figure 4). Both import the numerical code of `scripts/kitti/plot_figures.py` and `scripts/gate/plot_observability.py` and change only the styling. They need numpy, scipy, matplotlib and the VIFT `src` package (see the root `README.md`).

## Inputs

| Variable | Content |
|---|---|
| `KD` | KITTI pose dump of the VIFT reproduction (epoch 144, trained with drive 08): the folder that holds `05_estimated_poses.npy`, `07_…`, `10_…` and the `*_gt_poses.npy` files. Cached in `results_cache/july_dump/` (Kaggle kernel `vift-kitti-dump`). |
| `GYRO` | `<seq>_gyro_R.npy`, `<seq>_gyro_maxgap_s.npy` and `calib_2011_09_30.json`, built with `scripts/audit/build_score_inputs.sh`. |
| `NPZ` | `05.npz`, `07.npz`, `10.npz`. |
| `RAW_CALIB` | Folder that holds `2011_09_30/` (KITTI raw calibration). |
| `KGEO` | `05/07/10_geo_dir.npz`, the KITTI two-view geometry. |
| `EUROC_DUMPS` | Folder that holds `pivift_s123_last/<seq>_{estimated,gt}_poses.npy` for MH_05_difficult, V2_02_medium, V1_01_easy and V1_02_medium. Regenerated by the Kaggle kernel `scripts/kaggle_kernels/kernel_euroc4_s123_infer`; the cached copy is `results_cache/euroc4_s123/tumft/pose_dumps_pivift_s123_last` (link it as `EUROC_DUMPS/pivift_s123_last`). |
| `EUROC_GEO` | `<seq>_geo.npz`, four sequences: `results_cache/2026-10-28/euroc_geo`. |
| `OUT` | Output folder for the figures. |

## Commands

Run from the repository root with a Python that has the packages above (`PY=python`).

```bash
PY=python
KD=results_cache/july_dump
EUROC_DUMPS=results_cache/euroc4_s123/dumps          # contains pivift_s123_last -> tumft/pose_dumps_pivift_s123_last
EUROC_GEO=results_cache/2026-10-28/euroc_geo
GYRO=...; NPZ=...; RAW_CALIB=...; KGEO=...          # inputs listed above
OUT=figures_out && mkdir -p "$OUT"

# Figure 3: heading error (writes $OUT/kitti_heading_error.pdf)
$PY scripts/scireports/fig_heading_error.py "$KD" "$GYRO" "$OUT"

# Figure 4: measure vs learn (the last argument is the output PDF)
$PY scripts/scireports/fig_measure_vs_learn.py "$KD" "$KGEO" "$NPZ" "$GYRO" "$RAW_CALIB" \
    "$EUROC_DUMPS" "$EUROC_GEO" "$OUT/observability_measure_vs_learn.pdf"
```

The scripts use Arial 7 pt, lines of at least 1 pt and TrueType (Type 42) fonts, so the PDFs stay vector.

## Known difference from the earlier PNG

In Figure 4a the EuRoC curve has three extra bins below 2 px of parallax (about 0.8, 1.1 and 1.5 px; error difference about 45–75°) compared with the earlier PNG. The bins use the same edges and the same cached geometry; the cause was not found. The statement in the figure caption (measuring is better by 50–110° on EuRoC) does not change.
